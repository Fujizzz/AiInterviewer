# 工作台布局调整

调研日期：2026-10-03。参考公开的官方产品说明与页面，没有将登录后的完整产品体验视为已验证事实。

| 参考产品 | 官方资料呈现的组织方式 | 本项目采用的设计判断 |
| --- | --- | --- |
| [Linear](https://linear.app/docs/teams) | 按团队组织工作区，首页集中常用资源与入口 | 共用稳定导航，主内容围绕当前任务展开；首页提供明确的任务入口 |
| [Yoodli](https://yoodli.ai/feature-announcements/your-secret-weapon-for-interview-prep-interview-scenarios) | 先准备岗位/场景，再练习面试 | 准备继续放在开始前的弹窗，面试主区域集中题目、画面和语音作答 |

以上是设计参考，不代表这些产品拥有与本项目相同的后端能力。顶部导航、简历分区和面试双栏是结合本项目现有流程作出的设计选择。

## 导航和信息层级

- 所有产品页面共用 `workspace-nav.html`：概览、模拟面试、我的简历、岗位推荐、面试复盘。账号菜单包含个人信息与 CSRF 退出。
- 面试复盘保持独立 `/interview-review/` 页面与顶部入口。
- 首页作为工作台概览，展示练习主入口、准备—练习—复盘流程和快捷卡片；开发诊断折叠为次级入口，不显示未经查询的统计或健康状态。
- 简历页按 URL 哈希显示附件/历史、在线编辑、岗位推荐、个人信息；岗位入口为 `/resumes/#job-recommendations`。各分区保留同一 DOM 与业务状态，切换不调用接口、不保存或清空草稿。版本预览、解析成功和推荐资料核对会显示对应分区。
- 普通同页顶部导航保留草稿，新标签页快捷键遵循原生链接行为；离开页面的未保存确认保持原样。
- 面试桌面主栏包含当前问题、画面、字幕和回答按钮；侧栏包含时间、阶段、题目/话题进度、异常和设备设置。设备设置折叠，语音状态与错误仍位于回答按钮下方。
- `workspace.css` 统一阅读宽度、文字层级、卡片边界、操作间距与焦点。窄屏顶部导航在自身区域滚动，主内容按 DOM 阅读顺序排列。

## 实现边界

本次只调整呈现与页面内导航。推荐仍为既定 topk1=20、topk2=5；面试预算、题数、追问限制、语音时限和接口契约不变。没有引入隐式保存、重试或模型替代。

共享样式加入静态资源白名单和账号页公开资源精确路径；简历、面试、复盘 HTML 与业务 API 的认证边界保持不变。空数字人播放器显示品牌占位，不表示已连接；播放器挂载后占位消失。

## 验证

- 前端脚本测试覆盖未保存稿的分区切换、推荐字段定位与哈希导航，原面试/语音/历史测试继续运行。
- Django 模板测试覆盖统一导航、独立复盘、登录门禁、转义身份、CSRF 与共享样式交付。
- 浏览器使用真实 Django 模板、实际前端脚本和合成简历/问题/岗位响应检查桌面与手机视口。合成数据只用于本地预览；该检查不验证真实供应商、麦克风、摄像头或数字人服务。
- 部署流水线执行后端/前端测试与服务器健康检查；真实认证推荐冒烟仍使用部署环境配置的岗位库和 LLM。

具体运行结果和当前部署版本以交付说明及 GitHub Actions 记录为准。
