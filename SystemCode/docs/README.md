# Documentation index

These paths are relative to the application root `SystemCode/`. The submission-level overview,
reports and videos are one level above that root. See [the layout guide](REPOSITORY_LAYOUT.md)
for the exact boundary and [the user guide](../../ProjectReport/Installation-and-User-Guide.md)
for current startup commands.

- [Repository reorganization and verification](REPOSITORY_REORGANIZATION.md): source moves,
  preserved runtime/deployment contracts, baseline comparison and remaining limitations.

- `architecture/PROJECT_ARCHITECTURE.md`: system-wide architecture and team boundaries;
- `modules/AGENT_MODULE_DEVELOPMENT.md`: detailed Agent design;
- `modules/AI_SECURITY_BEHAVIOR.md`: current interview input/output boundaries and integration;
- `archive/ai_security/README.md`: immutable historical security evidence; retired commands are not current interfaces;
- `modules/EVALUATION_AGENT_DEVELOPMENT_PLAN.md`: phased plan for evidence extraction, behavior-anchored scoring, deterministic aggregation, and Evaluation integration;
- `modules/EVALUATION_MAIN_INTEGRATION.md`: main integration conflicts, compatibility fixes, migration paths and verification results;
- `guides/FILE_GUIDE_ZH.md`: current repository file guide;
- `guides/DIGITAL_HUMAN_SETUP.md`: local UE avatar, speech configuration, packaging and acceptance;
- `examples/agent_contracts.py`: documentation-only contract example.

The executable shared contracts are in `shared/contracts/`, not in `docs/examples/`.
