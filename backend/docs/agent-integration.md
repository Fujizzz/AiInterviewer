# 临时 Agent 接入草案

状态：正确仓库已提供 `agents/orchestrator/service.py` 的 InterviewAgentService 和 `app/application.py` 的 MVP 应用组合。当前后端只完成独立 REST 与 WebSocket 诊断，以下网络 Agent 接口仍是草案。

接入时应复用根目录的 `shared/contracts/` 契约与 `agents/ports/`，不要在后端重新实现第二套面试决策中心。真实模型供应商适配已存在于 `app/`；本次重构不改变其既定策略、参数或失败处理。

## 接入边界

- 现有 `/ws/echo/` 保持为传输诊断，不将原样回传误标为 Agent 回答。
- Agent 使用独立入口 `/ws/agent/`，由后端适配模型服务，前端不持有模型密钥。
- 测试输入、输出和会话上下文仅保存在内存中；不新增数据库表、文件日志或浏览器持久存储。
- Agent 与模型提供方解耦，提供方和模型名须显式配置；未配置时明确返回错误，不自动启用模拟实现或更换模型。
- 如果使用外部模型，应用不落盘不代表外部提供方不保留请求；接入前需确定实际服务及数据流向。

## 文本流协议草案

前端请求：

```json
{"type":"generate","request_id":"<UUID>","input":"<测试输入>"}
```

服务端按顺序返回：

```json
{"type":"started","request_id":"<UUID>"}
{"type":"delta","request_id":"<UUID>","sequence":1,"text":"<增量文本>"}
{"type":"done","request_id":"<UUID>"}
```

失败返回 `error`，包含 request_id、code 和适合展示的 detail；不暴露密钥、供应商原始错误体或完整输入。
取消请求为 `{"type":"cancel","request_id":"<UUID>"}`，后端取消生成并关闭上游响应，返回 cancelled。
同一连接同时只运行一个请求；生成期间第二次 generate 明确返回 busy，不隐式排队或覆盖。
断线时取消上游调用；不自动重连、重发或重试计费请求。

## 音视频边界

当前音视频仅证明分片能够回传。若 Agent 要理解麦克风输入，需要明确语音转写或实时语音模型；若要返回语音，还需语音合成或原生音频输出能力。
不能将 MediaRecorder 的 WebM 分片未经格式与协议适配就当作任意模型可识别的输入。

## 接入前需要确定

- 复用现有 MVP 的应用级适配方式，以及网络会话与 Agent 状态的映射。
- 真实服务的 API 地址、模型名、认证方式；密钥由本地环境变量提供。
- 第一阶段输入是文字，还是麦克风音频；输出是文字流，还是语音。

## 验证目标

- 增量内容在完成前到达，并按 request_id、sequence 更新对应 UI。
- 上游超时、认证失败、断线、取消、重复请求均有明确状态，不报告虚假成功。
- 流式测试前后数据库内容不变，媒体与文本不写文件。
- 接入真实服务后才报告真实模型调用通过；协议模拟测试单独标识。
